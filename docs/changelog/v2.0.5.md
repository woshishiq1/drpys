## 新功能

- 设置中心新增「直播」配置分组：LIVE_URL 支持多订阅（分号/换行分隔，每条生成一个直播入口），EPG_URL/LOGO_URL 全局共享；配置写入 config/env.json，未配置时回退 .env 环境变量
- 直播源自动扫描 json/lives 目录 .txt/.m3u 文件，每文件一个直播入口（原 json/tv 目录迁移至此）
- lxserver 适配升级至 2.0.1：/lx Web 播放器与 /admin 后台转发重构
- hgProxy 新增 DASH MPD BaseURL 重写与全方法转发（仅限本机回环目标）
- 哔哩影视[官] 新增 B站DASH 线路：V2 接口 + wbi 签名 + try_look 游客试看，proxy_rule 动态生成标准 MPD（avc1 多码率+最高音轨，需 EXO 内核壳子），配 bili_cookie 可达 1080P
- 新增短剧库、短剧库6源 两个桥接源
- 夸克/UC/阿里/哔哩/百度扫码取消时返回「扫码已取消」提示而非空响应

## 修复

- 设置中心 action 自调用地址改写仅限 http 非标端口：https 反代部署不再被降级为明文 http 回环导致扫码全挂
- B站扫码 cookie 标准化：URL 查询参数格式（& 分隔含 gourl/Expires 等杂项字段）过滤转换为标准 cookie（; 分隔），确保 SESSDATA 可入库
- /mediaProxy 多线程 Range 分支补 reply.hijack()：pipeline 中途出错不再对已发 206 头的响应二次 send（ERR_HTTP_HEADERS_SENT unhandledRejection）
- hgProxy IPv6 回环校验修复：URL() 返回的 hostname 带方括号（'[::1]'）导致白名单永不命中（fail-closed，无安全风险）
- mediaProxy content-length 缓存跳过 m3u8/event/DASH 类响应：直播流同一 URL 内容随时间变化，缓存总长会切出错误 Range
- pathGuard/pathHelper 项目根前缀校验补分隔符边界：兄弟目录（如 ../drpy-node-evil/x）不再因前缀重叠误放行
- 全局钩子 /js /py 分支统一 pwd 校验写法：pwd 403 后不再对已应答的 reply 续跑文件头重写
- /lx/*、/music/*、/admin/*（lxserver 转发）显式声明 public 对齐旧版匿名语义：配置了 Basic 账密的部署中壳子音乐源不再 401（/lx、/music 精确入口维持 Basic）
- deny-by-default 鉴权二轮回归修复：/clipboard/* 页面 JS 自带 Bearer 头与全局 Basic 打架导致浏览器无限弹认证框，连同首页 /、/docs/*、/authcoder、/gh/release、/ws/status、/ws/broadcast、/captcha/status（源探测依赖）、/req/*、/ai 共 10 条旧版匿名语义路由补 auth:public 豁免；管理面 /admin/*、/image 写接口等维持默认 Basic 收紧
- json/tv 目录改名 json/lives 后 live2cms 系列配置引用未同步（误写 ./live/ 与漏改 ./tv/）：IPTV直播、IPTV四川[官] 的本地直播线路全部 404
- 直播转点播[合] 线路拉取补传条目自定义 headers（此前仅播放阶段生效）：在线 TXT 线路被 kstore CDN 掐连接导致分类无数据；拉取为空自动重试一次，规避代理链路对 CDN 的间歇性 TLS 建连失败
- fileHeaderManager 正确处理 py 文件 PEP 263 coding 声明与 shebang 前缀：红果漫剧.py 的 @header docstring 不再重复插入、coding 声明不再失效
- 腾云驾雾[官] 修复：旧 pagesheet 接口下线后迁移 getMVLPage 频道接口（筛选实时 dump、构造式翻页），精选改用首页运营位接口与推荐数据源分离

## 重构

- 鉴权从「白名单 Basic、其余放行」反转为「默认 Basic + 路由级 config.auth 声明豁免（public/pwd）」：新增私有路由默认受保护，无需改动 index.js
- mediaProxy 重写：axios 连接池 + content-length 缓存 + stream/promises pipeline 替代手写资源管理器；Range 解析防 NaN；多分片流失败即中止（不再错位续传）；移除每连接 8MB 预读缓冲（起播更快、内存更低，4K 高码率抗上游瞬时抖动能力有所下降）
- mediaProxy 附带修复旧版两处 bug：play_proxy_mode=2 线程数传字符串、多分片流中途失败错位续传

## 安全

- /php/、/cat/、/catLib/、/xbpq/ 静态目录从匿名放行收紧为 API_PWD 校验（未配置 API_PWD 的部署不受影响）
- hgProxy 转发目标从任意 http(s) URL 收紧为本机回环（localhost/127.0.0.1/::1）
